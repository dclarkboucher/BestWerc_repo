# BestWerc_repo
This repository provides companion code for our article, "Historical Control
Data Borrowing Using Bayesian Evidence Synthesis Tactics With Error Rates 
Control". To replicate the results from the paper, open the file 
"BestWerc_repo.Rproj" to start RStudio in the appropriate working directory. 
Then use the script "master.R" to run the analysis components sequentially. The 
output will be stored in the results, figures, and tables folders. 

Some of the simulation studies may take several hours to finish. To run 
smaller and faster versions of the simulations, open the corresponding R script 
and reduce the "nreps" parameter.
